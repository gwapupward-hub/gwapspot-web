# GWAP Website

The official public gateway for the GWAP ecosystem at [gwapspot.com](https://gwapspot.com).

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- Vercel

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run lint
npm run build
```

## Current scope

Phase 1 establishes the public brand foundation: homepage, ecosystem directory, roadmap, community links, SEO metadata, favicon/logo integration, responsive design, robots, sitemap, manifest, and initial legal pages.
