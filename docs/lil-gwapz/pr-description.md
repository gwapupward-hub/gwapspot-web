# Lil Gwapz: selected homepage, reaction finder, and original-quality PNGs

The previous download flow enlarged 192-pixel atlas cells into 512-pixel files, discarding the quality available in the approved masters. The later purple homepage also differs from the user's selected original #3.

This change builds Pick Your Vibe at `/lil-gwapz` and the original #2 reaction finder at `/lil-gwapz/browse`. All 152 reactions have searchable character filters, a large preview with light/dark backgrounds, direct original PNG downloads, and native file sharing where supported.

Downloads are the unchanged 1254 × 1254 transparent source PNGs. Responsive WebP previews keep browsing lighter. A provenance manifest documents six verified archive-label swaps while preserving source bytes. Static, versioned artwork totals roughly 278 MB before QA screenshots; it is served on demand, not bundled into client JS.

Validation: production build, typecheck, scoped ESLint, seven catalog/integrity tests, and desktop browser interaction checks pass. A browser-triggered download matches the master SHA-256. Mobile viewport design QA and device-native sharing remain unverified; `design-qa.md` stays blocked pending phone viewport evidence. No production deployment is requested in this draft.
